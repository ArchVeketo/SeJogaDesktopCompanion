# Se Joga Desktop Companion — v0.1.0 (pré-release)

Primeira versão pública do Mário no seu desktop. Pré-alpha: use para experimentar e dar feedback.

## Instalação

1. Baixe o `SeJogaCompanion-Setup-windows-x64.exe` abaixo.
2. Execute. Não precisa de Python nem de nada instalado.
3. O Mário aparece no seu desktop.

Windows 10/11 x64.

## O que tem nesta versão

**O mascote vivo**
- Mário 3D interativo, sempre por cima das janelas, sem bloquear seus cliques (overlay transparente com clique-através).
- Animação totalmente procedural: nenhuma pose é pré-gravada engessada.

**Movimento com peso e vida**
- Molas amortecidas em todas as juntas, com tensão própria por parte do corpo (ombros firmes, mãos leves, dedos soltos) — movimento com peso e inércia, independente da taxa de quadros.
- Respiração: o peito infla e esvazia, o mascote nunca fica totalmente estático.
- Idles vivos com personalidade.
- Contorno estilo street que acompanha a pose e "respira" junto.

**Interação**
- Passe o cursor: ele olha para você e entreabre a porta.
- Clique esquerdo: cutucada. Clique direito: carinho. Botão do meio: reação de surpresa.
- Arraste com física real; solte em movimento para arremessar. `Esc` cancela o arraste.

**Música**
- Dança sincronizada com a batida (Windows Media Session ou áudio do sistema).

**Tentáculos**
- Emergem da porta da cabeça, com física própria e gosma rosa.

**Atualizações**
- Nas Configurações você escolhe o canal de atualização e busca atualizações; também pelo menu da bandeja.

## Controles

| Ação | Efeito |
| --- | --- |
| Hover | Olha para você, entreabre a porta |
| Clique esquerdo | Cutucada |
| Clique direito | Carinho |
| Botão do meio | Reação de surpresa |
| Arrastar | Segura e move; solte para posicionar (`Esc` cancela) |
| Ctrl + Alt + S | Abre as configurações |

## Observações desta pré-release

- É uma pré-alpha: ainda há ajustes de estética e comportamento em andamento.
- Verificação de integridade por SHA256 acompanha o instalador (`.sha256`). Assinatura de editor (Authenticade) ainda não está configurada — o Windows pode exibir aviso do SmartScreen; é esperado nesta fase.
